# Dynamic HR Frontend

React + TypeScript + Vite frontend for Dynamic HR Demo.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
```

The dev server runs at:

```text
http://localhost:5173
```

The API base URL defaults to:

```text
http://localhost:5154/api
```

Override it with `frontend/.env` or `frontend/.env.local`:

```text
VITE_API_BASE_URL=http://localhost:5154/api
```
